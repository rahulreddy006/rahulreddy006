AI-powered SaaS platform that analyzes resumes against job descriptions using Gemini AI, ATS scoring, keyword matching, Redis queues, BullMQ background processing, and real-time updates with Socket.io.

**Tech Stack:** React.js, Node.js, Express.js, PostgreSQL, Prisma, Redis, BullMQ, Socket.io, Gemini AI

🔗 **Live Demo:**
